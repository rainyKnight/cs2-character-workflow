# 共用第一人称基础手模

工作流只随附这一种角色资产，清单在 `assets/shared-hands/manifest.json`。它是已经接受的干净素手，保留手指、指甲、UV、法线和蒙皮；不包含人物身体网格、衣服、袖套、头发、耳尾或整个人物成品。源 DMX 的骨架包含导出时的动画兼容骨，并不代表这些骨骼和数量是所有角色的标准。

用户人物由用户提供，技能不要求某种人物名称、某个参考模型、固定妆容或固定体型。共用手资产的原始命名空间是依赖标识，不作为选角和脚本分支条件。源文件与 compiled 材质/纹理通过 manifest 哈希核对。

使用步骤：

1. 从手资产 manifest 读取源 DMX、网格和依赖。保留资源路径闭包，或者有完整映射地迁移命名空间；不只改其中一个材质路径。
2. 检查当前项目的第一人称动画骨架和坐标约定，复用手模需要的骨名/绑定映射。不能把手部 DMX 自带的全部骨架原封不动复制为人物主体骨架。
3. 由用户人物生成袖套，匹配腕口位置、尺度、衣服材质和手臂动作；袖套是每角色适配项，不属于共用素手。
4. 指甲保留独立材质。默认使用随附基础外观，项目可调整肤色、指甲颜色/粗糙度；不能为了调色破坏已接受的手几何或把整只手染成指甲颜色。
5. 交付前检查手指握持、腕缝、袖口、第一人称露腿、持不同类型武器与切换/重生。素材被复用不等于所有新角色已免测试。

资产原始来源在随附 manifest 中记录；仓库没有包含其它人物素材或提供 Source 2 编译工具。工具由用户本地环境提供。
